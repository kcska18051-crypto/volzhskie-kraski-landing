# Волжские краски

Текущая четвёртая версия B2B-лендинга. HTML, CSS и ES modules, без сторонних зависимостей и внешних запросов на странице.

Требуется Node.js 22 или новее. Зависимостей npm нет: npm install не требуется.

```powershell
npm run dev
```

Предпросмотр: http://127.0.0.1:4173. Сервер привязан только к loopback.

```powershell
npm test
npm run build
node scripts/serve.mjs --dist
```

Сборка создаёт `dist/`. Перед запуском сервера сборки нужно остановить предыдущий сервер на порту 4173. `review/` и `docs/` в сборку не включаются.

Форма проверяет данные локально: компания, контакт и описание задачи либо непустой выбранный файл. Адаптер в `src/forms.mjs` не делает сетевых запросов и не сохраняет данные. Выбранный файл не загружается. Реальные заявки, Тильда, аналитика и публикация не подключены.

Подробности: [отчёт и материалы для следующего этапа](docs/review.md), [арт-дирекция](docs/design-v4.md), [происхождение материалов](docs/assets.md).


Подтверждение контактов: в src/contacts.mjs задать согласованные label и value, затем confirmed: true отдельно для телефона и email. До подтверждения остаётся ссылка на официальный раздел контактов. Статусы готовности и ожидания материалов перечислены в docs/review.md.



## Состав репозитория

Исходники, локальные ассеты, шрифт с лицензией, скрипты, тесты и проектная документация. dist, node_modules, секреты, внутренние отчёты и временная папка review исключены. Для генерации локальных QA fixtures: node scripts/review-fixtures.mjs.

Права и лицензии: [ASSET-RIGHTS.md](ASSET-RIGHTS.md). Публикация репозитория не включает размещение сайта и подключение доставки заявок.
